### 1. Cabecera (hero)

### 2. El problema (iconos + texto breve)
- 📞 Miles de consultas ciudadanas diarias
- ⏳ Colas y tiempos de espera
- 📂 Información dispersa en múltiples webs
- 💸 Coste operativo creciente

### 3. La solución (diagrama de flujo)
```
CIUDADANÍA → Widget flotante → MASTER AGENT → 10 Agentes especializados → RAG con citas → Respuesta
```
- Iconos de los 10 agentes en fila (Ciudadano, Trámites, Normativa, Documentos, Urbanismo, Empresa, Social, Cultura, Idiomas, Historia)

### 4. Capacidades PRO (iconos + métricas)
| Capacidad | Métrica |
|---|---|
| 🤖 Multi-agente | 10 agentes especializados |
| 📚 RAG con citas | 100% hit rate (13/13) |
| 🌐 Multilingüe | gl / es / en |
| 🙋 Human-in-the-Loop | Escalación real a Supabase |
| 🧠 Memoria | Conversaciones persistentes |
| 🔗 MCP | Integración externa (tools/list, tools/call) |

### 5. Stack tecnológico (logos)
- Next.js 15 · React 19 · Tailwind
- OpenRouter (modelos free) · Gemini

- Vercel + GitHub

- 🇪🇸 8.000+ ayuntamientos en España
- 📈 Modelo: licencia por municipio + soporte + actualizaciones

- 🔗 Integrable: Sede Electrónica, Registro, gestor documental
