# Reporte a Google Safe Browsing — Dominio vigo-ai-demo.vercel.app

**CHESS AI AGENCY · 18/11/2026**

---

## Contexto

El dominio `vigo-ai-demo.vercel.app` fue marcado por Google Safe Browsing como "sitio engañoso" (deceptive site). La causa probable fue el uso de datos sintéticos que simulan ser del Concello de Vigo (nombres, direcciones, procedimientos), lo que puede haber sido interpretado como phishing o suplantación de identidad.

## Acciones ya realizadas

1. ✅ Añadido banner visible: «DEMO GRATUITA — datos 100% sintéticos, no oficiales».
2. ✅ Disclaimer en el widget: «Asistente IA de demostración. No soy un empleado municipal.»
3. ✅ Texto legal en el footer: «DEMO GRATUITA v1.0 · Servicio de demostración con IA; no representa el Concello de Vigo ni ofrece información oficial.»
4. ✅ Creación de dominio neutro `ia-administracion-local.vercel.app` para la campaña (sin marca Vigo).
5. ✅ Headers de seguridad (CSP, HSTS, X-Frame-Options, etc.).

## Nota importante

Mientras el flag persista, el dominio `vigo-ai-demo.vercel.app` puede mostrar advertencias en Chrome. Por eso se creó el dominio neutro `ia-administracion-local.vercel.app` para la campaña. Una vez levantado el flag, se puede volver a usar `vigo-ai-demo.vercel.app` para todo.
